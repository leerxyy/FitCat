# Материалы RITUA

## Логотип и интерфейсная графика

- `assets/logo.svg`: тёмный горизонтальный векторный логотип.
- `assets/logo-light.svg`: светлая версия.
- `assets/favicon.svg`: знак в квадрате.
- `assets/icon-192.png`, `assets/icon-512.png`: иконки PWA.
- `assets/icon-maskable-512.png`: безопасная зона для маскируемых иконок.
- Иллюстрации рецептов создаются в SVG в `app/icons.js`.
- Пиктограммы адаптированы на основе геометрии Lucide; лицензия — `licenses/lucide-ISC.txt`.
