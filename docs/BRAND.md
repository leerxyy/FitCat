# RITUA

**Забота в вашем ритме.**

RITUA — персональное пространство для ежедневного благополучия. Продукт адресован специалистам, руководителям и предпринимателям с насыщенным графиком: людям, которым нужны быстрые действия, понятная картина дня и спокойный интерфейс.

Бизнес-сегмент здесь означает качество опыта, ясность и комфорт использования. Это персональное приложение; кабинеты работодателей и наблюдение за сотрудниками в продукт не добавлены.

## Характер бренда

Спокойный, уверенный, внимательный. Премиальность выражается в типографике, расстояниях, материалах и предсказуемости действий. Основной акцент — на самочувствии, а не на соревновании с другими пользователями.

Вместо монет и коллекционных рамок на первом плане находятся дневник, вода, движение и ритуалы. Базовые задачи не закрыты искусственными ограничениями. Демо отделено от личных записей.

## Визуальная система

| Роль | Цвет |
| --- | --- |
| Основной зелёный | `#2C5140` |
| Чернильный текст | `#253E33` |
| Фон | `#F7F7F2` |
| Поверхность | `#FFFEFA` |
| Подложка навигации | `#F0F1EA` |
| Мягкий зелёный | `#E6ECE0` |
| Тёплый акцент | `#BA8056` |
| Вода | `#749E9D` |
| Белки / жиры / углеводы | `#63846C` / `#C5A578` / `#9C9AB3` |

Вечерняя тема использует тёмные зелёные поверхности и тёплые светлые буквы. Контрастные показатели и состояния поддерживаются цветом, текстом и формой.

Основной шрифт — системный sans-serif. В эмоциональных сообщениях, дыхательной паузе и заголовках диалогов используется Georgia с системным serif fallback. Это сохраняет кириллицу и работу без загрузки шрифтов из внешних сервисов.

Радиусы основных карточек: 17–20 px. Кнопки: 8–9 px. Тени слабые; границы и свободное пространство задают иерархию. Анимации короткие, без непрерывного фонового движения. Учитывается системная настройка уменьшения движения.

## Знак

Знак соединяет букву R и восходящий штрих: личный ритм и небольшое движение вперёд. `assets/logo.svg` — горизонтальная версия, `assets/logo-light.svg` — светлая версия. `assets/favicon.svg` и PNG — знак для установки и вкладки.

Минимальное свободное поле вокруг знака — четверть его ширины. Используйте цельный цвет; не добавляйте тени, обводки или растяжение.

## Тон

| Ситуация | Формулировка |
| --- | --- |
| Пустой дневник | «Здесь пока пусто — и это нормально» |
| Завершение паузы | «Вы нашли время для паузы» |
| Превышение цели | «Дневной ориентир превышен» |
| Удаление записи | «Запись удалена» + «Вернуть» |
| Ошибка сохранения | Конкретная причина; запись остаётся в форме |

Не использовать давление, стыдящие оценки тела, обещания результата и вымышленные медицинские рекомендации.

Название разработано как продуктовый бренд для этой версии. Отдельная проверка регистрации товарного знака не проводилась.
