# RITUA Atelier 2.0

**День, в котором есть место вам.**

Экспериментальная премиальная редакция RITUA. Персональное пространство с журнальной композицией, собственной фотосерией, выразительной типографикой и личным маршрутом дня. Версия 1.0 сохранена без изменений.

| Версия | Адрес |
| --- | --- |
| RITUA Atelier 2.0 | https://ritua-atelier.tinypike66.chatgpt.site |
| RITUA 1.0 | https://ritua-wellbeing.tinypike66.chatgpt.site |

Обе опубликованные версии имеют закрытый доступ владельца.

## Что изменилось

- Знак-печать, векторный логотип и новые иконки приложения.
- Новый первый экран: пространство тишины, маршрут дня, четыре повседневных ориентира и редакционная коллекция.
- Тёплые поверхности, оливковый цвет, тонкие линии, крупные заголовки и новая композиция шести разделов.
- Архитектурная фотография и единая фотосерия для шести рецептов.
- «Баланс», «Фокус» и «Мягкий день»: ритмы меняют расписание ритуалов, сохраняя цели питания, воды и движения.
- Настраиваемый маршрут: выбор ритуалов и времени, намерение на день и возможность оставить день без списка.
- Личная отметка самочувствия, намерение и заметка.
- Быстрый доступ по `Ctrl+K` / `⌘K`: действия, разделы, продукты и рецепты. Поддерживаются стрелки и Enter.
- Тихая комната на 1, 3 и 5 минут, пауза, продолжение и остановка при уходе в фон.

Дневник, произвольные порции, планирование, вода, ручная активность, статистика, вес, избранное, наборы и резервные копии сохранены.

## Запуск

Нужен Node.js 20 или новее. Установка зависимостей не требуется.

```bash
npm start
```

Откройте http://localhost:3000. Не открывайте `index.html` двойным щелчком: JavaScript-модулям нужен HTTP-сервер.

```bash
npm test
npm run build
node scripts/serve.mjs --dist
```

Для размещения загрузите содержимое `dist/` на статический HTTPS-хостинг. Поддерживаются корень и вложенный путь. После изменения исходников пересоберите проект: версия кэша вычисляется по содержимому файлов.

## Личные данные и демо

Первый запуск показывает явно обозначенный пример, который не записывается в постоянное хранилище. «Начать свой день» создаёт личный дневник без демонстрационных записей и измерений.

Дневные значения — ручные ориентиры, а не медицинское назначение. Пищевая ценность приблизительна; сверяйтесь с этикеткой конкретного продукта.

Дневник сохраняется в localStorage этого браузера. Два адреса не делят хранилище. Серверной синхронизации и обмена личными записями нет. Предыдущее корректное состояние сохраняется для восстановления. Ошибка записи оставляет введённые данные в форме.

Очистка браузера и приватный режим могут удалить записи. Регулярно скачивайте JSON-копию. Лимит импорта — 5 МБ. Отдельного шифрования паролем нет: доступ к открытому браузеру означает доступ к дневнику.

Внешний поиск Open Food Facts запускается только по действию пользователя и отправляет введённое название продукта. Встроенная база работает без интернета.

## Перенос RITUA 1.0 и FitCat

Скачайте JSON-копию в первой версии, затем выберите **Настройки → Восстановить RITUA / FitCat** в Atelier. Перед заменой приложение показывает количество дней и измерений и запрашивает подтверждение.

Atelier читает копии RITUA формата 1 и обновляет их до формата 2. Основные записи и настройки сохраняются. Новые поля — ритм, намерение и личное расписание — включаются в новый экспорт.

Копия Atelier формата 2 не предназначена для импорта обратно в RITUA 1.0. Она отклоняется старой версией без замены её данных. Для сравнения с одинаковой историей сохраните исходную копию 1.0.

Автоматический перенос FitCat возможен при обновлении на том же origin. Для нового адреса используйте JSON. Исходные ключи остаются нетронутыми; оригинальная копия сохраняется в поле `legacy`. Исторические итоги переносятся без вымышленных подробных продуктов.

## Проверка и границы

Пройдены 73 теста: 53 базовых сценария и 20 новых сценариев Atelier. DOM-стенд проверяет элементы и действия, но не CSS. Реальная визуальная проверка в браузере и на iOS/Android была недоступна. Сеансы проверены с управляемым временем, не на настоящих устройствах. Подробнее — `docs/VERIFICATION.md`.

Платежи, серверные аккаунты приложения, облачная синхронизация, распознавание еды, фоновые push-уведомления и интеграции с часами в эксперимент не добавлены. Вход в закрытую публикацию обеспечивает платформа размещения.

SVG-логотипы — `assets/logo.svg` и `assets/logo-light.svg`. Материалы и промпты — `docs/ASSETS.md`. Коммерческие шрифты и внешние библиотеки для запуска не требуются.
